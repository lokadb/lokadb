The application began to get 08001 "the agent of organization 5 is not connected", and on that output `php artisan serve` itself died (a failure parsing its own output, Carbon::createFromFormat); after that every request was "connection refused". This is a failure of the stand, not a result. Fixed in the stand: the application starts through `php -S` with Laravel's router, and before every variant http checks that the application answers and stops the variant if it does not. Laravel runs without LokaDB (plain) stay in `raw/`. Laravel through LokaDB was not measured again in the last pass.
